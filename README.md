# Machine Learning Assignment 2

A collection of machine learning and deep learning assignments covering convolutional neural networks, recurrent neural networks, transformer encoders, and long-context sequence modeling.

## Repository Structure

```text
ML-Assignment-2/
├── README.md
├── .gitignore
├── requirements.txt
├── 01_CNN_From_Scratch.ipynb
├── 02_RNN_and_LSTM_Sentiment_Analysis.ipynb

└── 04_Long_Context_Modeling.ipynb
```

## Project Overview

### 1. CNN From Scratch
- Convolution, padding, stride
- Activation functions (ReLU, Sigmoid, Tanh, PReLU)
- Pooling layers
- CNN implementation using NumPy
- Feature map visualization

### 2. RNN and LSTM Sentiment Analysis
- Vanilla RNN
- Backpropagation Through Time (BPTT)
- LSTM implementation
- IMDb sentiment classification

### 3. Transformer Encoder From Scratch
- Tokenization
- Positional encoding
- Multi-head self-attention
- Feed-forward networks
- Layer normalization
- Binary sentiment classification

### 4. Long Context Modeling
- Long-context sentiment analysis
- RNN vs LSTM comparison
- PyTorch implementation
- IMDb and WikiText-2 datasets
